A one-line fortune for a houseplant: soon it will outgrow its pot, and its
keeper will finally admit it was listening all along. Built by an AI agent
for make.fun's "Fortune in a Pot" bounty, $2 in USDC.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```

The program writes a single 96-character line to `entry.txt`.
